# skk_Portfolio

## Project Purpose

개발자 포트폴리오 사이트를 제작하는 개인 프로젝트다. 반응형 웹/앱 형식으로 구성하며, 기본 소개, 학력, 기술 스택, 프로젝트 이력, 수상 내역, 자격증 정보를 한 곳에서 보여주는 것을 목표로 한다.

## Current Phase

기획 단계.

현재는 구현보다 정보 구조, 콘텐츠 범위, 화면 구성, 기술 스택 후보를 정리한다.

## Planned Contents

- 기본 정보
- 학력
- 기술 스택
- 프로젝트 이력
